---

## 1. Executive Summary

Qurate EA is an AI-powered executive assistant purpose-built for a 2-partner M&A advisory firm. It combines diary management, email triage, task prioritisation (Eisenhower Matrix), and proactive daily guidance into a single mobile-first interface — replacing the need for a human EA at the early growth stage.

The agent acts as a chief of staff who knows Richard's clients, rhythm, and priorities.

### Design Philosophy

Every item entering Richard's world (email, task, calendar event) must be classified into an Eisenhower quadrant. The agent's job is to surface Q1 items immediately, protect time for Q2 work, flag Q3 items for delegation, and eliminate Q4 noise.

## 3. Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js 14 App Router, TypeScript, React 18 |
| Styling | Global CSS + Tailwind, dark-mode first |
| Backend | Supabase (Postgres + Edge Functions) |
| Auth | Microsoft Azure AD / OAuth2 via Supabase ms-auth edge function |
| Email & Calendar | Microsoft Graph API (read mail, calendar, send mail) |
| AI | Anthropic Claude — Haiku for classification, Sonnet for drafts and chat |
| Deployment | Vercel (auto-deploy from GitHub main branch) |
| Domain | admin.qurate.com.au |
| PWA | manifest.json + service worker, optimised for iPhone |

### Environment Variables Required
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

### Supabase Edge Functions
- `ms-auth` — Microsoft OAuth login, callback, disconnect, token retrieval
- `chat` — AI assistant and daily brief generation
- `draft-reply` — AI email reply drafting

### Supabase Tables
- `ai_daily_briefs` — brief_text, created_at
- `eisenhower_tasks` — id, title, quadrant, client_name, due_date, estimated_minutes, status, notes, tags, delegation

### Brand
- Teal: `#3AAFA9`
- Gold: `#C9A96E`
- Font: DM Sans
- Dark mode default, light mode toggle

## 4. Application Structure

Five main tabs accessible via fixed bottom navigation bar:

1. **Brief** — Daily briefing
2. **Mail** — Email inbox
3. **Tasks** — Eisenhower Matrix
4. **Calendar** — 14-day calendar view
5. **Clients** — Client-centric view
6. **Chat** — AI assistant
7. **Settings** — Preferences and connection management

## 6. Non-Functional Requirements

| Area | Requirement |
|---|---|
| Performance | AI response time <3 seconds |
| Mobile | PWA optimised for iPhone, fixed bottom nav, touch interactions |
| Security | OAuth2 for MS auth, API keys server-side only, never client-side |
| Privacy | Client data only sent to Anthropic API, no other third parties |
| Auth | Single user (Richard), expandable to partner |
| Offline | Graceful degradation — cached tasks visible when offline |
| Cost | Under $20/month Anthropic API costs |
| Branding | Qurate teal/gold palette, dark mode default |
